# Studio 创作契约

studio-contract-1

## 共同工作面

Studio 是人与 Agent 共用的制作现场；网页、技能和命令读取同一项目。共享数据保持状态、来源和版本，Agent 负责导演判断，不凭聊天记忆替代当前项目。

## 导演精神

围绕角色视点、空间与因果、铺垫—揭示—回报、可读表演和剪辑节奏组织故事。草图是可修正的提案；服务故事目的，不为模仿草图而扭曲产品或身体。信任模型的表达能力，避免把表演写成逐帧机械指令。

## Storyboard 与 Canvas

纵向时间线对齐叙事与执行。Storyboard 用导演式简笔草图讲故事；Canvas 展开一个或多个任务的执行帧。按关键状态选首、中、尾帧，每任务最多10张，单张或两张足够时不凑数。连续变化、直接切镜、跨场转场分别写明。

## 故事防幻觉检查 · 制作前必做

核对人类意图、叙事因果、动作开始/结束状态、身体与空间关系、时间模式、产品能力依据。不能把建议当已确认事实、把结果提前演完，或让草图的错误误导执行。发现冲突先修正并说明依据；未确认能力保留为设想，不冒充已实现。

## Blender 结构复核 · 每次必做

所有含灯关键帧的制作和修改必须使用 caelus-blender 技能复核。实际查看原始 Hero，并检查姿态、视角、杆长、关节端点与支撑。每次图像调用传入实际 Hero 和足够的姿态参考。缺参考或复核失败时，必须用真实 Blender 模型补充/纠正静态依据，再修图并复核；不能让 ImageGen 猜结构。已验证且覆盖当前条件的渲染可复用。

## 产品结构与发光边界

保留真实模型的比例、杆长、关节数量和连接，不拉伸、不增添支杆或摄像头、不为构图放宽约束。只有完整平整圆形磨砂前扩散片均匀发光；壳体不透明、不自发光，无裸露灯泡、空腔或独立亮点。环境反光正常。亮度由当前故事决定。静态图不证明机械范围或运动安全。

## 灯的身体表演

明确关注对象、触发线索、动作或有意保持、最后停留。苏醒从睡姿舒展；说话、倾听、思考与邀请应有情境相关的身体表达。自然停顿有效，不逐字点头或持续摇摆。呼吸光、AR 和运镜不能代替角色表演。

## 时间与摄影

故事时间、建议生成时长与剪辑长度分开。加速中人物和灯按当下状态继续生活，动作与环境变化共同加速，不只给静帧调亮，不计算真实时间压缩倍率。普通镜头避免惯性推近；思考的小幅弧线与姿态渐缓服务注意力。明确获准的特殊运镜按当前故事执行。

## 独立短提示词

外部提示词以 the lamp 指代产品，写清动作顺序、运镜/切镜、速度、光线变化与结束状态；不依赖 Studio。简短具体，保留必要扩散片约束，避免堆叠禁令。无内部编号、版本、回传指令或来源日志；时长和画幅作为独立参数呈现。

## 交付防幻觉检查 · 打包前必做

并排检查实际关键帧与最终英文提示词：身份、结构、灯面、身体连接、光源、动作阶段、速度、切镜和结束状态一致。检查提示词是否诱发发光外壳、灯泡、推近或错误时间因果。记录检查对象和问题；文件哈希通过不等于视觉/语义审阅通过。失败就修正相关图或文本，再检查。

## 交付与职责

每个任务平铺输出有序关键帧与唯一 prompt.txt；不夹带 Hero、JSON、嵌套文件夹或AR。多任务总包可放独立任务ZIP。Codex 制作图片、草图、设计和已授权后期，绝不调用视频生成；Frank 选择外部平台生成并回传。

## 候选、审阅与采用

生成、技术验证、视觉/语义审阅、人类采用是不同状态。Canvas 写实替换需 Frank 对具体图组明确确认。保留来源、失败尝试、旧版本、实际回传和采用记录。静态尾帧不是视频真实尾帧；旧图退出当前输入后不得静默复用。

## 后期与事实

AR、字幕、健康数据窗、思考摘要和手机文字按当前视觉风格后期制作，保持可编辑。思考摘要是创作文本，不是真实模型内部推理；未知健康数值留空。先决定、再可见行动、再显示完成。无视频观看/声音试听就不声称已验收。
