# Static image execution and structural review

Read the installed caelus-blender SKILL.md and relevant local-source reference. Resolve current asset roots from project.local.json and the project; old Console paths in historic receipts are provenance only. View original Hero Blender stills before EVERY lamp image call and attach them. Inspect the intended pose AND view; an existing generated scene can anchor continuity but never replace Hero authority.

Mandatory Blender review checks: actual source/rig, body and two-arm proportions, five-joint hierarchy where applicable to the inspected model, endpoint connectivity, support, interpenetration/occlusion, opaque shell and continuous circular front diffuser. Do not infer exact geometry from a thumbnail. No new camera, eyeball, extra rod, mid-arm pivot, stretching or constraint widening to solve composition.

If a needed view is missing or the output fails review: inspect/hash the actual .blend, work in a fresh derivative with embedded scripts disabled, use supported rig settings, render the needed static view, inspect it, and attach the real image to the corrective ImageGen call. Reblock impossible staging. Reopen reusable .blend deliveries and check their poses against renders. Follow the Blender skill rather than guessing axes.

Only the flat full front diffuser emits evenly. No visible bulb, inner cavity/hotspot, translucent housing or whole-head glow. Ambient reflection is allowed. Status breathing is distinct from practical reading light; the story decides intensity. Illustrative brightness labels are not hardware calibration.

Inspect the final full frame and enlarged lamp, then adjacent frames: structure, human anatomy, contact, spatial continuity, action phase, exposure and acting. Passing reference inspection does not pass generated pixels. Retain failed attempts and limited-visibility findings. Static review does not certify motion, speed, breathing rhythm or mechanical safety.

Record actual tool arguments, role-tagged input paths/hashes, model/render provenance and output hashes in existing project records. Do not label an AI-edited room a genuine Blender render. Obsolete sources remain excluded even if they look convincing.
